# Local reference measurements

These measurements came from Spark worker processes sharing one laptop: 10 CPU cores and 16 GiB RAM. The data study used 100 MB through 2 GB; the worker study used 500 MB with 1, 2, and 5 processes.

The Dataproc notebook uses fresh cloud runs and a 2 GB worker study. This archive preserves the original timing tables and figures from the earlier implementation.
